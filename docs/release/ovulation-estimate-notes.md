# Approximate ovulation timing — release note

Luna Cycle shows an ovulation-*timing estimate*, not a measured ovulation date or a fertile/safe-day classification. It is available only when the existing period prediction has at least three completed start-to-start cycle intervals. One or two intervals, an expired prediction, or a long untracked gap do not produce this estimate.

For each approximate next-period start range, the earliest possible date is shifted back 16 days and the latest possible date is shifted back 10 days. The first range is not allowed to begin before the latest recorded period start. This intentionally broad interval includes uncertainty in the expected period date; it does **not** mean ovulation lasts throughout the interval. The estimate updates or disappears when period records change or become stale. It is computed locally from saved period starts and does not introduce a new data collection or sharing path.

The 10–16-day reference comes from [NHS guidance](https://www.nhs.uk/conditions/periods/fertility-in-the-menstrual-cycle/). [ACOG](https://www.acog.org/womens-health/faqs/fertility-awareness-based-methods-of-family-planning) describes ovulation as about 14 days before the next period in an average cycle. [CDC guidance](https://www.cdc.gov/contraception/hcp/usspr/standard-days-method.html) emphasizes that fertile-window timing varies substantially even with regular cycles. Therefore this feature must never claim a confirmed ovulation day, contraception safety, or a definitive fertile window. Users should not rely on it alone for pregnancy planning or prevention.
